STRATTIQ favicon and social share

Upload every file in this folder to the root of strattiq.com (same folder as index.html).
If your domain is different, replace https://strattiq.com in the tags below.

Files
  favicon.svg, favicon-16/32/48.png   Browser tab icons
  apple-touch-icon.png (180)          iPhone home screen
  favicon-192/512.png + site.webmanifest   Android and installable app
  og-image-launch.png (1200 x 630)    Share image for the launch page (no reveal)
  og-image-website.png (1200 x 630)   Share image for the full website, use after launch

<link rel="icon" href="/favicon-32.png" sizes="32x32" type="image/png">
<link rel="icon" href="/favicon-16.png" sizes="16x16" type="image/png">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
